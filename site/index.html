Oxocarbon Grey

A dark theme for VS Code, Zed and Neovim. Oxocarbon’s colours on a flat, cool grey, tuned for Python, Rust, TypeScript and C++.

Install Source on GitHub

Point at a colour to see what it marks. Select one to keep it.

Colours as the Neovim port draws them with Tree-sitter (). VS Code and Zed use the same palette, with small differences in how each editor reads the code.

Five steps of grey

Surfaces climb a few shades at a time, so the current line, menus and selections stand apart from the editor without heavy borders. Text uses four more greys, and only code gets colour.

Install

VS Code

From the VS Code Marketplace or Open VSX. Keep semantic highlighting on.

code --install-extension viraj-s15.oxocarbon-grey

Zed

Not in Zed’s extension registry yet. Clone the repository, click Install Dev Extension on the Extensions page and choose the zed folder.

git clone https://github.com/viraj-s15/oxocarbon-grey

Neovim

Neovim 0.10 or later with true colour. Styles Telescope, Gitsigns and blink.cmp. With lazy.nvim:

{
  "viraj-s15/oxocarbon-grey",
  lazy = false,
  priority = 1000,
  config = function()
    vim.cmd.colorscheme("oxocarbon-grey")
  end,
}

Options, plugin support and review steps are in the README.
