Oxocarbon Grey

A dark theme for VS Code, Zed, Neovim, Ghostty and herdr. Oxocarbon’s colours on a flat, cool grey, tuned for Python, Rust, TypeScript and C++.

Open VSXVS Code Marketplace

Point at a colour to see what it marks. Select one to keep it.

Colours as the Neovim port draws them with Tree-sitter (). VS Code and Zed use the same palette, with small differences in how each editor reads the code.

Five steps of grey

Surfaces climb a few shades at a time, so the current line, menus and selections stand apart from the editor without heavy borders. Text uses four more greys, and only code gets colour.

Sixteen for the terminal

VS Code, Zed, Neovim, Ghostty and the herdr desktop app share one set of terminal colours. Oxocarbon has no yellow, so yellow is purple. Red, green, yellow and magenta keep their colour when bright.

The theme changes programs that print these sixteen colours. Programs that pick their own 24-bit colours, such as Neovim with this theme, draw those instead.

Install

VS Code

From the VS Code Marketplace or Open VSX. Keep semantic highlighting on for the full effect.

  1. Install the extension:

    code --install-extension viraj-s15.oxocarbon-grey

  2. Pick Oxocarbon Grey in the Color Theme picker.

Zed

Not in Zed’s extension registry yet, so it installs as a dev extension. Keep the clone, because Zed loads the theme from it.

  1. Clone the repository:

    git clone https://github.com/viraj-s15/oxocarbon-grey

  2. Click Install Dev Extension on the Extensions page and choose the zed folder, not the repository root.

  3. Pick Oxocarbon Grey in the theme selector.

Neovim

Neovim 0.10 or later with true colour. Styles Tree-sitter, LSP semantic tokens, Telescope, Gitsigns and blink.cmp.

  1. Add the plugin with lazy.nvim:

    {
  "viraj-s15/oxocarbon-grey",
  lazy = false,
  priority = 1000,
  config = function()
    vim.cmd.colorscheme("oxocarbon-grey")
  end,
}

Ghostty

A custom theme, separate from Ghostty’s built-in Oxocarbon. Colours in your own config, like background or palette, override it.

Download the theme file or read its source.

  1. Download the theme into Ghostty’s themes folder. The download is skipped if the file is already there:

    dir="${XDG_CONFIG_HOME:-$HOME/.config}/ghostty/themes"
mkdir -p "$dir"
[ -e "$dir/oxocarbon-grey" ] || curl -fsSL -o "$dir/oxocarbon-grey" \
  https://viraj-s15.github.io/oxocarbon-grey/ghostty/oxocarbon-grey

  2. Add this line to your Ghostty config, or change your theme line to it. On macOS, Settings… in the Ghostty menu opens the config.

    theme = oxocarbon-grey

  3. Reload with Cmd+Shift+, on macOS or Ctrl+Shift+, on Linux.

herdr

One theme for the desktop app, which colours the terminals and panels. A second one for the terminal app colours its sidebar, tabs and popups, and its panes keep your terminal’s colours.

Download the desktop theme or the terminal theme, or read their source.

Desktop app

  1. Download the theme into the themes folder. herdr-app finds it live, so no restart is needed:

    dir="${HERDR_APP_HOME:-$HOME/.config/herdr-app}/themes"
mkdir -p "$dir"
curl -fsSL -o "$dir/oxocarbon-grey.json" \
  https://viraj-s15.github.io/oxocarbon-grey/herdr/oxocarbon-grey.json

  2. Pick oxocarbon-grey in Settings → Look, or run this. Each layout keeps its own theme.

    herdr-app do app.theme --name oxocarbon-grey

Terminal app

  1. Remove any [theme.custom] table from your herdr config.

  2. Add the theme to the end of the config, then reload the server:

    {
  printf '\n'
  curl -fsSL https://viraj-s15.github.io/oxocarbon-grey/herdr/oxocarbon-grey.toml
} >> "${HERDR_CONFIG_PATH:-$HOME/.config/herdr/config.toml}"
herdr server reload-config

Neovim options and build commands are in the README.
